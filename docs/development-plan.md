## 性能評価の方法

ファイルサイズに加えてページ数、画像数、OCR比率、非空セル数、抽出文字数、要約トークン数を記録します。平均とp95、失敗率、ピークメモリ、読み取りバイト数を形式別に集計します。

夜間時間の概算は、`全対象のハッシュ時間 + 新規/変更分の抽出時間 + OCR対象の処理時間 + チャンク要約と統合時間 + 出力時間`です。重複再利用を差し引き、実測の20%以上の余裕を持たせます。初回は総処理量を夜間実働時間で割って必要夜数を見積もります。

1,200件×30MB≒36GBはI/O評価の例です。同じ36GBでも画像数・ページ数でOCRと要約時間は大きく変わります。実機で容量計画を確定するまで、一夜に1,000件完了等の固定目標は置きません。
